# Volta&Meia

#Volta & Meia — E-Commerce de Móveis & Decoração

#Status do Projeto: Em Desenvolvimento (Fase de Front-End & Prototipagem Interface UI/UX)

O Volta & Meia é um conceito de e-commerce moderno e minimalista focado na venda de móveis modulares e itens de decoração. O projeto foi idealizado para entregar uma experiência de navegação fluida, intuitiva e responsiva, inspirada nas melhores práticas dos grandes players do mercado visual e varejista.

#Sobre o Projeto

Atualmente, o projeto encontra-se em sua primeira etapa de desenvolvimento, focada na construção de toda a interface visual e na estrutura de experiência do usuário (UI/UX). Toda a base de layout está desenvolvida utilizando padrões modernos de estilização, garantindo alta performance de carregamento e adaptação total a dispositivos móveis.

#Interface & Funcionalidades Atuais (Front-end)

Layout Responsivo: Adaptação completa para desktop, tablets e smartphones.

Componentes de Vitrine: Exibição de produtos com grids organizados, cards de destaque e banners promocionais.

Navegação & Fluxo de Usuário: Estruturação de telas de navegação por categorias, página de produto e fluxos básicos de carrinho e checkout visual.

Estilização Moderna: Design limpo e foco na legibilidade das informações de produto.

#Tecnologias Utilizadas nesta Fase

HTML5: Estrutura semântica e acessível.

CSS3: Customização visual, layout flexível (Flexbox/Grid) e animações de interface.

JavaScript (Vanilla): Interatividade básica de UI (manipulação de DOM, abas e menus).

Bootstrap 5: Agilidade na estruturação responsiva e componentes reutilizáveis.

#Próximos Passos & Roadmap

O projeto foi planejado de forma modular para receber integrações complexas nas próximas etapas de desenvolvimento:

[ ] Banco de Dados (Relacional): Modelagem e estruturação do banco para gestão de produtos, categorias, clientes e pedidos.

[ ] Integração de APIs

[ ] Back-end & Regras de Negócio: Implementação de autenticação de usuários, persistência de carrinho de compras e painel administrativo.

[ ] Refatoração JS: Expansão da lógica de estado no client-side para comunicação dinâmica via Fetch/Axios.

OBS: O projeto dependendo da fase pode parecer inacadado e não funcional, isso ocorrerá por estar em fase de desenvolvimento
